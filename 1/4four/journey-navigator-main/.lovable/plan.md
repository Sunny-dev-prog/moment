## 二、视觉风格：**「极简地形拓扑图」**

不是传统瓦片地图（土），不是蛇形（假），而是一张深绿底色上的**未来感探险者手绘图**：

| 层级 | 内容 | 表现 |
|---|---|---|
| L0 背景 | 与图1一致的深绿径向渐变 | 雾绿→森林绿→深绿 |
| L1 地理暗示 | 极淡 SVG 等高线/地形轮廓 | 1px 白色 8% 透明，暗示阿尔泰山脉、准噶尔盆地、伊犁河谷三块地形分区 |
| L2 区域 chip | 三个浮动小标签 | "阿尔泰山区 · 北疆"｜"准噶尔戈壁 · 中段"｜"伊犁河谷 · 南疆"，弱化处理 |
| L3 路线 | 青绿色发光折线连接 12 节点 | SVG `path`，沿真实方位走，虚线流动动画，体现"行进感" |
| L4 节点 | 12 个发光圆点 + D 编号 | 真实地理位置定位 |
| L5 信息卡 | 玻璃拟态小卡，从节点引出 | 公里数/时长/路况，自动避让边界 |
| L6 指北针 | 右上角小 N↑ | 强化"这是真实地图"的认知 |

**为什么是这个风格**：
- 放弃瓦片地图 → 不破坏深绿氛围
- 保留真实方位 → 满足你的硬性要求
- 加等高线/地形分区 → 信息密度足够，不空
- 青绿发光线 → 与图1 UI 语言一致

## 四、节点交互（高亮 + 侧边小卡）

- 默认：12 个节点显示发光圆点 + D 编号 + 一行迷你信息（如 `D2 · 320km`）
- **点击节点** → 该点放大发光，引出一张玻璃拟态详情卡（公里数 / 时长 / 路况难度 / 路段类型 / 一句话亮点），其它节点淡化为 40% 透明
- 详情卡位置自动避让屏幕边界（左侧节点卡片向右弹，右侧向左弹）
- 再次点击 → 收起

**路况三档**：🟢 低难（高速国道）｜ 🟡 中难（缓弯/河谷）｜ 🔴 高难（盘山/戈壁）

## 五、数据层：Lovable AI 实时生成

启用 **Lovable Cloud** → Edge Function `generate-route` 调用 AI Gateway（`google/gemini-3-flash-preview`），用 **tool calling** 强制返回结构化 JSON：

```json
{
  "days": [
    { "id": "D1", "from": "阿勒泰机场", "to": "阿勒泰市",
      "km": 25, "hours": 0.5, "difficulty": "low",
      "roadType": "市区道路", "highlight": "落地即雪山入城" },
    ... D2 – D12
  ]
}
```

- 前端 mount 调用 `supabase.functions.invoke('generate-route')`
- 加载时显示骨架屏（地图+节点已在，信息 shimmer）
- 24h localStorage 缓存
- 右上角 🔄 强制重新生成
- 处理 429 / 402 错误并 toast 提示

**AI 系统提示词**：
> 你是新疆北疆自驾路线规划师。基于"阿勒泰进、伊宁出"的12天环线，按 D1–D12 顺序输出每天的真实公里数、行车时长、路况难度（low/mid/high）、路段类型、一句话亮点。数据需符合真实地理常识。

## 六、技术实现

1. **新建组件**：
   - `src/pages/Index.tsx` — 页面容器
   - `src/components/card4/PhoneFrame.tsx` — 顶部导航 + 底部 Tab（无状态栏，可复用）
   - `src/components/card4/Card4Route.tsx` — 卡片4 主体
   - `src/components/card4/GeoMap.tsx` — SVG 真实方位地图（等高线 + 区域 chip + 路线折线 + 节点）
   - `src/components/card4/DayNode.tsx` — 节点 + 详情卡（含避让逻辑）
   - `src/lib/route-coords.ts` — 12 节点真实方位坐标常量

2. **后端**：
   - Edge Function `supabase/functions/generate-route/index.ts`
   - 用 tool calling 返回 schema 化 JSON

3. **设计系统** token（`index.css` + `tailwind.config.ts`）：
   - `--card-bg-from / via / to`（深绿渐变）
   - `--card-glass / --card-glass-border`
   - `--road-stroke / --diff-low / --diff-mid / --diff-high`
   - `--terrain-line`（地形等高线色）

4. **响应式**：9:16 移动端竖屏（375 × 812）基准，桌面预览居中。
