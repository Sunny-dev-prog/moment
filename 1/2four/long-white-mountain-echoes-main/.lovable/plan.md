## 卡片4 最终方案：盗墓笔记长白山·个性化卡片墙

延续前3张卡片的容器外壳（顶部导航 / 4/4 角标 / 左右翻页箭头 / 底部"不感兴趣 + 查看详情" / Tab Bar / 页面指示器），整页比例 5.9:19，内部是融合青铜门背景的多板块卡片墙。

### 一、背景融合（关键，让背景图自然融入）

三层叠加：
1. **底层渐变**：上 25% 浅蓝雪景 (#d6ecf5 → #c4dff0) → 中 50% 过渡灰蓝 (#a8c5d8) → 下 25% 深青蓝 (#3a4a66 → #2d3a52)
2. **中层背景图**：你提供的青铜门图作为 `background-image`，居中铺满，应用 `opacity: 0.45` + `mix-blend-mode: soft-light` + 上下边缘 `mask-image` 线性渐变羽化，让图片像"水印记忆"般融在中段
3. **顶层氛围**：极淡蓝白噪点纹理 + 15-20 片 CSS 飘雪粒子（呼应前3张"雪雾弥漫"）

→ 效果：背景有故事感、有盗笔气质，但不抢前景文字风头，整体仍是浅蓝清爽基调与前3张和谐。

### 三、7 个微交互（全部卡片内交互，不跳转）

1. **主卡轻翻转**：点击主卡 → Y轴 3D 翻转 180°，背面显示「北纬41°42′ 东经128°03′」+ 麒麟图腾极简图标，再次点击翻回
2. **主卡长按发光**：长按主卡 → 古铜金边框光晕呼吸 + 周围浮起金色微粒
3. **主卡轮播**：左右滑动切换 3 张（好久不见 / 带我回家 / 长白山见）
4. **撕边车票&便签可拖动**：手指按住可在雪地区域内拖动，拖动时轻微旋转抖动，松手回弹
5. **卡币翻转**：点击「邪/灵/胖」卡币 → 翻面显示「吴邪/张起灵/王胖子」
6. **雪花飘落**：板块B区域内持续飘落小雪花粒子（CSS keyframes，缓慢下落+左右摆动）
7. **小卡呼吸漂浮**：所有散落小卡 4-6s 上下浮动 ±3px，错开延迟，营造"漂在雪上"

切换板块C的 Tab 时，下方内容 fade-in + 上滑 12px。

### 五、视觉与字体

- 主标题：黑色粗体 + 蓝色高亮关键词（同前3张风格）
- 主卡文案：刻宋体感（serif + 粗 weight），古铜金 #c9a96e
- 手写便签：手写体（引入 Google Font `Liu Jian Mao Cao` 或 `Ma Shan Zheng`），墨黑/藏蓝
- 副文案小字：深灰 / 哑金
- 卡片样式：圆角 + 毛玻璃 `backdrop-blur-md` + 半透明白底 + 浅蓝边框（呼应前3张），让青铜门背景隐约透出
- 撕边车票：CSS `mask` + `border-dashed` 边模拟撕痕
- 卡币：圆形 + 古铜金边 + 中间方孔

### 六、技术实现

- 路由：替换 `src/routes/index.tsx`（当前是 placeholder）
