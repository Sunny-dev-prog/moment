## SVG 洱海轮廓设计

- 用一条手绘风格的闭合 `<path>` 描出洱海狭长南北走向的轮廓（像参考图里的形状：北宽、南窄、东岸略凸）。
- 填充：半透明青蓝色（`rgba(120,180,190,0.35)`），描边：白色虚线 1.5px，营造"路线"感。
- 沿轮廓外侧/内侧用 `<circle>` + `<text>` 标记 7 个打卡点，每个点是个小白圈，旁边是细体小字标签：
  1. 上关花（北端）
  2. 喜洲古镇（西北）
  3. 才村码头（西）
  4. 龙龛码头（西南）
  5. 海舌公园（南，标"终"）
  6. 小普陀（东南）
  7. 挖色镇（东）
  8. 双廊（东北）
- 路线起点用一个橘色脉冲点（带 CSS `animate-ping`）做"出发"提示。

## 背景层

- 卡片整体背景：从顶部冷青到底部暖橘的渐变（沿用前三张的暮色调），叠一层模糊的骑行女生背影做大背景虚化（`opacity-20`，`blur-sm`）。
- 卡片本身用 `backdrop-blur-xl` + `bg-white/10` + 圆角 `rounded-3xl`。

## 配色 & 字体

- 主背景渐变：`#cdd6cf → #d9c4a3 → #e8d0a8`
- 高亮强调色：青蓝 `#2f5d68`、橙 `#f08d3a`
- 标题：粗体白色 + 部分文字描边/青色高亮（参考图 1、3 的混排样式）
- 字体：系统默认 sans + 中文用 `font-semibold`，无需额外字体包
