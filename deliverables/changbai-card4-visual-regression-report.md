## 分辨率回归结果

基于 `PhoneFrame` 的卡片宽度公式：

- `width = min(92vw, (100vh - 32px) * 9 / 16)`
- 标题容器宽度固定为 `max-width: 258px`

文本在 `25px` 字号下的实测宽度：

- `这些滑雪姿势` = `150px`
- `简直不要太帅了` = `175px`

对比结果：

| 视口 | 卡片宽度 | 标题容器宽度 | 最长单行文本宽度 | 结论 |
| --- | ---: | ---: | ---: | --- |
| 375 x 812 | 345.00px | 258px | 175px | 无截断、无溢出 |
| 414 x 896 | 380.88px | 258px | 175px | 无截断、无溢出 |
| 768 x 1024 | 558.00px | 258px | 175px | 无截断、无溢出 |
| 1920 x 1080 | 589.50px | 258px | 175px | 无截断、无溢出 |

## 一致性结论

- 字号差异：`0%`
- 颜色差异：`0%`
- 行高误差：`0px`

判定依据：

- 新标题与 CARD 4 标题直接复用同一公共类与同一 CSS 变量
- 未引入新的字号、颜色或行高覆盖
