## 用户需求

修复每个主题卡片2的视频加载错误。目前每个主题的卡片2显示的视频内容不正确。将视频源路径修改为正确结构：`total/chapter-[n]/sp[n]-1` 和 `total/chapter-[n]/sp[n]-2`，确保 `[n]` 对应当前章节编号。

## 核心功能

- 修正 `d:/xm/total/chapter-5/` 目录中视频文件命名错误（`sp4-1.mp4` → `sp5-1.mp4`，`sp4-2.mp4` → `sp5-2.mp4`）
- 修正 `d:/xm/total/chapter-6/` 目录中视频文件命名错误（`sp4-1.mp4` → `sp6-1.mp4`，`sp4-2.mp4` → `sp6-2.mp4`）
- 修复 `d:/xm/total/ABC.json` 中 chapter-1 的 `sort2` 路径 typo（`.total//chapter-1/sp1-2` → `./total/chapter-1/sp1-2`）

## 技术解决方案

### 问题定位

1. **文件命名错误**：`chapter-5` 和 `chapter-6` 目录中的视频文件使用了 `sp4` 前缀，应为 `sp5` 和 `sp6`
2. **JSON 路径 typo**：`ABC.json` 中 chapter-1 的 `sort2` 值为 `.total//chapter-1/sp1-2`（双斜杠，缺少点号）

### 实现策略

- 使用 PowerShell 重命名命令修正视频文件名
- 直接编辑 `ABC.json` 文件修复路径 typo
- 无需修改代码逻辑（`resolveMediaPath` 函数已正确处理路径映射）

### 验证方案

- 重命名后检查文件是否存在
- 修复 JSON 后验证格式正确性
- 重启开发服务器后在浏览器中确认视频加载正常
