# 标题色板规范

## 适用范围

- 当前收口范围：主题 `002`
- 覆盖对象：页面主标题、卡片标题、导航栏标题态文字、底部导航当前项、主题卡片内的小标题态文字
- 统一令牌：`--card4-title-color`

## 主题 002 色板

- 主标题色：`#567883`
- 弱化标题色：主标题色配合 `0.58` 到 `0.82` 透明度使用
- 默认回退标题色：`#b08f9f`

## 使用规则

- 浅色背景下，标题先按目标亮度提升约 `15%` 到 `25%`，再通过对比度校正确保不低于 `4.5:1`
- 深色背景下，标题在保持色相不变的前提下继续提亮，并通过同一套对比度校正逻辑兜底
- 小标题、导航高亮项、当前页签优先复用 `--card4-title-color`，避免再写独立硬编码标题色

## 实现说明

- 颜色计算入口：`src/lib/colorUtils.ts`
- 标题公共样式：`src/index.css` 中的 `.theme-shared-card-title`
- 当前项目未使用 `Sass` 或 `Less`，因此不存在额外的 `scss/sass/less` 标题变量需要同步更新
